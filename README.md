# 🚀 DevOps & Linux Foundations: Interactive Mastery Quiz

A clean, interactive, and mobile-friendly HTML/JS application designed to test and validate fundamental DevOps engineering skills. Perfect for students, self-taught engineers, and IT instructors evaluating baseline knowledge.

---

## 🎯 Project Overview
This lightweight, single-file application provides a 10-question multiple-choice quiz covering the most critical aspects of modern software deployment and infrastructure management. 

It is completely self-contained (no backend database required) and features a dynamic progress bar, interactive UI, and instant performance grading.

### 💡 Core Topics Assessed:
*   **Linux Navigation & Permissions:** (`pwd`, `apt update`, `chmod 755`)
*   **Web Server Administration:** (Nginx paths, graceful reloading)
*   **Containerization:** (Docker Images vs. Containers, Detached port mapping)
*   **Cloud Storage:** (AWS S3 Global Naming Rules)
*   **Infrastructure as Code (IaC):** (Terraform definitions, Initialization & Apply lifecycles)

---

## 🛠️ Tech Stack & Features
*   **HTML5 & CSS3:** Semantic structure with responsive design.
*   **Tailwind CSS (CDN):** Rapid, utility-first styling for a polished, professional UI without external stylesheet files.
*   **Vanilla JavaScript:** Handles application state, user selections, DOM manipulation, and score calculation dynamically.
*   **Zero Dependencies:** Runs instantly in any modern web browser without needing `npm install` or local servers.
